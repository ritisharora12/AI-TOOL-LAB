AI Tools Lab

Project Description

AI Tools Lab is a Python project that contains commonly used sorting algorithms and utility functions. The project is designed for learning and practicing Python programming concepts, algorithms, and reusable functions.

Features

- Sorting algorithms for arranging data.
- Utility functions for common operations.
- Simple and reusable Python code.
- Easy to understand and use.
- Suitable for learning and laboratory practice.

---

Installation

1. Clone the Repository

git clone https://github.com/your-username/AI-Tools-Lab.git

2. Move into the Project Directory

cd AI-Tools-Lab

3. Run the Python Program

python main.py

«Make sure Python 3.x is installed on your system.»

---

Usage

Example 1: Sorting a List

from sorting import bubble_sort

numbers = [5, 2, 8, 1, 3]

result = bubble_sort(numbers)

print(result)

Output:

[1, 2, 3, 5, 8]

Example 2: Using a Utility Function

from utils import calculate_average

numbers = [10, 20, 30, 40, 50]

average = calculate_average(numbers)

print(average)

Output:

30.0
